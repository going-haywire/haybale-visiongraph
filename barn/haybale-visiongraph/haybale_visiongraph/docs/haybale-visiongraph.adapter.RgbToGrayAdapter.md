# RgbToGrayAdapter

`haybale-visiongraph:adapter:RgbToGrayAdapter` · kind: adapter

Convert a 3-channel colour frame to a single-channel grey frame (luminance)

## Details

- **converts_from**: `haybale-visiongraph:type:RGB_FRAME`
- **converts_to**: `haybale-visiongraph:type:GRAY_FRAME`
- **priority**: `0`

## Notes

RGB_FRAME -> GRAY_FRAME via luminance.
